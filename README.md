Цель этого ДЗ

Провести мини-претрейн LLM, чтобы: 

понять как устроен процесс pretrain изнутри;

потренироваться на малом масштабе: токенизация, обучение, логирование, анализ генераций;

почувствовать, что такое loss и как он ведёт себя во времени;

получить первые осмысленные генерации.


Сетап

Для обучения предлагаем использовать образ из Dockerfile и шаблон со скелетом решения, который вы можете заполнить. Шаблон можно изменять, но следует убедиться, что:

1. Модель совпадает.

2. Датасет и разделение на train/test совпадает.

3 Обучение длится 30 минут (в шаблоне используется callback для этого).

Для логирования можно использовать wandb. Чтобы оно работало, в шаблоне есть функция initialize_wandb. Нужно установить переменную WANDB_API_KEY, чтобы залогиниться в аккаунт. 

Что вам нужно сделать

1. Возьмите датасет и протокенизируйте его 

Загрузить через dataset = load_dataset("wikimedia/wikipedia", "20231101.ru", split="train")

ВАЖНО! Первые VALIDATION_SIZE=5000 семплов отходят в тестовый сет

Используйте токенизатор  "ai-forever/rugpt3small_based_on_gpt2"

Длина блоков токенизации фиксирована MAX_LENGTH=512

1.1 Инициализируем модель с нуля

Используем архитектуру qwen3 суммарно на 1b параметров. Конфиг и функция для создания модели есть в скелете решения. Изменять архитектуру нельзя.

2. Запустите pretrain

Для обучения исследуйте следующие параметры: 

Найти оптимальные batch_size (per_device_train_batch_size, gradient_accumulation_steps), learning_rate, lerning_rate_scheduler

torch_compile

оптимизаторы (optim)

использование специальных dtype под gpu (bf16, tf32)

Обучайте модель в течение 30 минут на 1GPU уровня A100


3. Проанализируйте результаты первичных генераций

После обучения задайте модели промпт на ваш выбор.

Запустите evaluation и зафиксируйте финальный eval_loss.

К концу эксперимента ваша модель:

учится предсказывать локальную структуру языка;

снижает perplexity;

даёт чуть более “языкоподобный” текст.
