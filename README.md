# Review Bench

Учебный курс для проверки домашних заданий по опубликованным условиям и рубрикам. Откройте ветку hw_N с условием, затем назначенную сдачу.

Идентификаторы участников синтетические и не обозначают авторство исходных материалов. Источник исходных материалов: https://github.com/ai-talent-hub-avito/homework_examples. Дополнительное Python-задание подготовлено для этого учебного курса.
